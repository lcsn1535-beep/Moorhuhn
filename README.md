# Hühnerjagd — Browser Arcade Shooter

Ein eigenständiges, Moorhuhn-inspiriertes Browsergame mit eigener Grafik und eigenem Code.

## Lokal starten
Öffne `index.html` im Browser. Es werden keine Build-Tools benötigt.

## Auf GitHub Pages veröffentlichen
1. Erstelle ein neues Repository auf GitHub.
2. Lade `index.html`, `style.css` und `game.js` in das Repository hoch.
3. Öffne **Settings → Pages**.
4. Wähle **Deploy from a branch**, den Branch `main` und den Ordner `/ (root)`.
5. Speichere. Nach kurzer Zeit ist das Spiel über die angezeigte GitHub-Pages-Adresse erreichbar.

## Steuerung
- Maus bewegen: zielen
- Linksklick: schießen
- `R`: nachladen
- `Esc`: pausieren/fortsetzen
- 60 Sekunden pro Runde
- Highscore wird lokal im Browser gespeichert (`localStorage`)

## Funktionen
- Startseite im Arcade-Look
- Canvas-Spiel mit beweglichen Cartoon-Zielen
- Punktesystem, Trefferquote, Timer und Munition
- Nachladen, Pause, Neustart und Ergebnisanzeige
- Soundeffekte via Web Audio API, umschaltbarer Sound
- Bonus-Ziele, Partikeleffekte und lokaler Highscore
- Responsive Layout für Desktop und Mobilgeräte

Das Projekt ist ein Fan-inspiriertes, eigenständiges Spiel und ist nicht mit Spielaffe oder den Rechteinhabern des originalen Moorhuhn-Spiels verbunden. Es verwendet keine Original-Assets.
